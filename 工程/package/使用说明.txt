桌面美化分区 · Windows 安装说明

适用于 Windows 10/11 64 位电脑。
将整个 ZIP 解压到一个文件夹，双击“一键安装.exe”。
安装完成后桌面会出现五个中文分类分区及一个桌面分区，并随 Windows 登录自动启动。
如果新电脑已在运行 PecoFence，请先从其托盘菜单退出。
安装程序需要新建安装目录。如果同名目录已存在，会给出提示。

包含当前修改版 PecoFence 0.4.0，五个分区的配色、视图和自动归类规则。
新文件、文件夹、快捷方式会自动归类，并滚动到新项目、选中图标。
搜索快捷键为 Alt + Q。桌面直接输入文字可唤起搜索。
按 Esc 关闭搜索。
桌面直接输入搜索的实机按键和中文输入法首字仍需在新电脑验证。
不同分辨率下，安装程序会按新电脑主显示器调整分区位置和大小。
安装时会检测 Everything 和 WebView2，并在缺少时从各自的官方下载地址联网安装。

主程序固定安装到 D:\home_bug\PecoFenceNative，Everything 固定安装到 D:\home_bug\Everything。新电脑需要有 D 盘；无论安装包解压到哪里，双击“一键安装.exe”都会使用上述位置。WebView2 为微软系统组件，其安装位置由微软安装程序管理。
实际文件和软件由新电脑自己提供，归类规则会用于新电脑的桌面内容。

源码基于 https://github.com/DayuanJiang/PecoFence 的 v0.4.0。
本包附有许可证和修改过的 Rust 源文件，便于继续维护。
此修改版的功能由本地维护。更新到官方版本可能覆盖自定义功能。
全局搜索优先显示桌面匹配项。没有桌面匹配时，同一搜索框会显示必应选项。按回车或点击该项，即可用默认浏览器搜索。
外部文件拖到桌面空白处后按规则归类，目标分区自动滚动并选中到达的项目。
全局搜索会同时显示本机 Everything 索引的文件和文件夹。安装时如缺少 Everything，会从 voidtools 下载 1.5.0.1409a x64 安装程序，核对签名及 SHA-256。首次安装索引服务时，请确认 Windows 权限提示。首次建立索引期间，搜索结果会逐步出现。没有桌面匹配时，回车仍默认使用必应，可用方向键或鼠标选择下方的本机结果。
文件夹、办公文档、工程图档和图片与其他是桌面上的真实目录。应用快捷方式仍在桌面。F1 开始截图。鼠标悬停可识别窗口或控件，拖动框选，松开后可用浮动工具栏调整选区、标注和保存。Enter 复制，Ctrl+T 将选区原位贴出，C 复制指针处的颜色。点击“识字”使用 Windows 本地 OCR 并复制识别结果。
F2 将剪贴板中的图片、图片文件或文本贴出。拖动移动，滚轮缩放，Ctrl+滚轮调透明度，右键打开贴图菜单，Esc 关闭。截图时点击历史或按逗号、句号打开24小时内最近十张截图的缩略图面板，点击图片复制原图并结束截图，Esc 返回原选区，它们保存在当前用户的 %LOCALAPPDATA%\PecoFenceNative\CaptureHistory。
修改截图和贴图快捷键：右键系统托盘的 PecoFence 图标，打开“截图和贴图快捷键…”，分别选择修饰键与主键，点击保存立即生效。恢复默认后也需点击保存。
分区外仅显示回收站，不创建文件管理器快捷方式。

截图界面恢复为原来的文字按钮与系统样式。最新标注在开始下一笔前可移动、修改颜色和粗细；矩形、椭圆、马赛克支持八个控制点缩放，直线与箭头支持端点调整。选区工具用于调整截图范围。Ctrl+Z/Ctrl+Y 支持新增标注与修改操作的撤销和重做。
文字标注：独立字号 14/18/24/32/48 px 与加粗，多行输入，Enter 换行，Ctrl+Enter 或点击画布提交。最新文字可双击重新编辑；Esc 取消本次文字编辑并恢复原文。复制、保存与贴图不会包含编辑框或控制点。

历史缓存保留规则：复制、保存和贴图产生的截图历史只保留24小时（仍最多十张）。打开截图、查看历史或新增历史时立即清理；安装程序同时创建每15分钟执行的用户级清理任务。电脑关闭或未登录时不能执行，之后打开截图会补清。Windows 任务默认电源条件可能暂停电池模式下的定时执行。仅清理 CaptureHistory 目录中的历史缓存，不删除手动另存为的图片，也不清空剪贴板。

登录启动：安装时为当前用户创建零延迟登录任务，电池供电也会启动。软件设置中的“随 Windows 启动”管理此任务。分区先显示，壁纸加载完成后自动更新背景。任务按新电脑的实际用户创建，程序默认位于 D:\home_bug。
Creo 语言兼容：简体中文 Windows 安装时设置当前用户 PRO_LANG=chs，避免继承英文工具环境导致启动后变为英文。已运行的 Creo 需下次启动才会采用新的语言设置。

Everything 联动：桌面软件启动时启动 D:\home_bug\Everything\Everything.exe 和其索引服务，正常退出时关闭程序并停止索引服务。Everything 不再独立开机自启，服务按需启动。安装时会请求管理员确认，为当前用户授予该服务的启动、停止和状态查询权限，之后日常启动无需管理员权限。

退出后可从桌面或开始菜单的“桌面美化分区”图标重新打开。直接双击已安装的 PecoFenceNative\pecofence.exe 也会自动读取旁边 config 中保存的分区样式、位置和规则。

桌面美化分区是基于 PecoFence 的独立项目。更新和问题反馈见 https://github.com/zhd01062016/desktop-layout-organizer 。
